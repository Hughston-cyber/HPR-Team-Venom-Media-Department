# HPR - Team Venom Media Department

A static, responsive media department website for Team Venom Human Powered Racing.

## Files
- `index.html` — complete single-page website (HTML + CSS, no build tools required).

## Deploy with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. Your site will appear at https://hughston-cyber.github.io/HPR-Team-Venom-Media-Department/.

## Before publishing
- Replace the placeholder `teamvenom.media@example.com` email address with the correct department contact.
- Replace the “Coming soon” feed items and featured collection panels with the real gallery, video and portfolio links.
- Add the approved Team Venom logo/favicon when available.

The site uses a black, charcoal and venom-green visual system inspired by Viper AI, and is mobile responsive.
